# MSA Cinema

تطبيق IPTV بشكل نتفليكس للتلفزيون (Android TV / Google TV)، بيشتغل باشتراك Xtream Codes.

## التسطيب على التلفزيون
1. من متجر Google Play على التلفزيون نزّل تطبيق **Downloader** (من AFTVnews).
2. افتحه واكتب اللينك ده في خانة العنوان:

```
https://github.com/drmsa30926/msa-cinema-tv/raw/main/MSA-Cinema.apk
```

3. دوس Go، وبعد التحميل دوس **Install**. لو طلب إذن «تثبيت تطبيقات غير معروفة» لـ Downloader، فعّله.
4. افتح MSA Cinema وحط بيانات اشتراكك: السيرفر واليوزر والباسورد.

> الملف ده مافيهوش أي اشتراك أو بيانات دخول — كل واحد بيحط اشتراكه.
